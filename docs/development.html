ClusterLab Development

ClusterLab is intentionally small: FastAPI, SQLite, Pydantic, and build-free browser JavaScript.

Local setup

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
clusterlab

Quality checks

python -m ruff check .
python -m ruff format --check .
python -m pip_audit
python -m build --sdist --wheel
python -m pytest

Repo rules

  • Use .html files for docs intended to be read by users.
  • Keep runtime data, local databases, research notes, virtual environments, and generated package metadata untracked.
  • Prefer typed API boundaries and small modules over broad dictionaries at new extension points.
