ClusterLab Demo Script

  1. Install with python -m pip install -e ".[dev]".
  2. Start clusterlab --offline-demo and open http://127.0.0.1:8765.
  3. Offline demo mode makes no provider calls; use live mode only after configuring an OpenAI-compatible endpoint.
  4. Review the default hats and edit one system prompt or tool permission.
  5. Open the topology canvas, pan/zoom, drag a structural node, and inspect validation messages.
  6. Run a task and watch the graph highlight active/completed nodes.
  7. Open Run Analysis to inspect prompts, outputs, blackboard deltas, token usage, and the final answer.
