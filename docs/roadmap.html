ClusterLab Roadmap

Near term

  • Finish splitting the remaining browser client into focused ES modules.
  • Add topology import/export for shareable presets.
  • Add richer run comparison and replay tools.
  • Improve cancellation semantics with a durable worker model.

Later

  • Provider profiles for multiple OpenAI-compatible endpoints.
  • Optional frontend tooling if the build-free client becomes a constraint.
  • More formal memory storage, review policies, and evidence artifacts.
